# Dear Chanel

Espacio personal: notas, tareas, calendario, escritorio de widgets, favoritos, reflexión diaria y copias de seguridad. Todo se guarda en LocalStorage.

## Usar en VS Code

1. Instala Node.js 18 o superior.
2. En la terminal de VS Code, dentro de esta carpeta:

```
npm install
npm run dev
```

3. Abre la dirección que aparece (normalmente http://localhost:5173).

Para generar la versión final: `npm run build` (queda en `dist/`).
